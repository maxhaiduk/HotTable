# DB problem emulator

Навчальний полігон для операцій з базою, які безпечні на 10 тисячах рядків і небезпечні на 20
мільйонах під навантаженням: індекси, зміни схеми, заповнення даних, видалення.

Кожна лаба складається з таких частин:
- дані;
- постійне навантаження;
- завдання;
- критерій успіху;
- розбір під спойлером.

Спершу робиш наївно і бачиш, як ламається, потім робиш правильно.

## Що всередині

- **`primary` + `replica`**: PostgreSQL 17 зі streaming replication. Сервери обмежені 2 CPU, щоб
  операції тривали довше і їх можна було роздивитись.
- **`make load`** (`tools/loadgen.py`): записи, читання і запит лаби. Щосекунди показує
  throughput, p99, помилки і `STUCK`, тобто скільки найстаріший незавершений запит уже чекає.
- **`make watch`** (`tools/status.sql`): сесії і на що вони чекають, хто кого блокує, прогрес
  побудови індексу, індекси, відставання репліки. Ці самі запити працюють на проді.
- **`labs/NN-*/`**: `README.md` із завданням, `seed.sql` з даними, `check.py`, який перевіряє
  результат.

## Вимоги

Docker з Compose v2 і ~15 ГБ диску для 20 млн рядків: у кожного з двох серверів ~2,7 ГБ даних і
до 4 ГБ WAL. Для меншого обсягу є `make seed ROWS=5000000`.

## Старт

```bash
make up      # primary + replica
make seed    # дані лаби 1, ~4 хв
make help    # усі команди
```

Далі відкривай [лабу 1](labs/01-index-on-busy-table/README.md).

## Веб-інтерфейс

```bash
make ui      # http://localhost:7070
```

Це єдина команда: вона піднімає стенд і заливає дані, якщо їх ще немає. Далі все в браузері,
одна сторінка замість кількох терміналів:
- зліва текст лаби, кнопка «↳ у psql» біля кожного SQL-блоку;
- справа живі графіки навантаження, стан бази (блокування, побудова індексу, індекси,
  репліка) і psql на primary та на репліці.

Для `make ui` потрібні Go 1.26 і Node 22+. Архітектура й наступні етапи описані в
[docs/ui-design.md](docs/ui-design.md). Розробка фронтенду з hot reload: `make ui` в одному
терміналі, `make ui-dev` в іншому.

Для GUI-клієнта (DBeaver, PhpStorm): primary на `localhost:55432`, репліка на `localhost:55433`,
`postgres` / `postgres`, база `lab`.

## Зупинка і скидання

```bash
make down    # зупинити, дані лишаються
make reset   # видалити все; потім make up і make seed
```
